【实践】Ubuntu20.04 Ollama+Dify Docker部署遇到的问题

项目学习需要，记录一下

2025年04月01日
阅读时长: 1 分钟
AI 摘要

Ubuntu 20.04安装Dify时Docker无法拉取镜像，需修改daemon.json配置国内镜像源并调整Ollama端口至11451。

问题：

1

Error response from daemon: Get "https://registry-1.docker.io/v2/": net/http: request canceled while waiting for connection (Client.Timeout exceeded while awaiting headers)

解决方案:

sudo gedit /etc/docker/daemon.json
并添加：

1
2
3
4
5
6

{
    "registry-mirrors": [
        "https://docker.1ms.run",
        "https://docker.xuanyuan.me"
    ]
}

sudo systemctl daemon-reload
sudo systemctl restart docker

运行Ollama

修改ollama service config文件中的port

[Unit]
Description=Ollama Service
After=network-online.target

[Service]
ExecStart=/usr/bin/ollama serve
User=ollama
Group=ollama
Restart=always
RestartSec=3
Environment="PATH=$PATH"
Environment="OLLAMA_HOST=0.0.0.0:11451"
OLLAMA_SCHED_SPREAD=1

[Install]
WantedBy=default.target

按照下面的方式运行ollama：OLLAMA_HOST=127.0.0.1:11451 ollama run qwq
