Python导出requirements.txt以及第三方库whl文件，方便以后部署到离线的服务器上

AI 摘要

使用pipreqs导出项目实际导入的第三方库生成requirements.txt，指定编码参数解决中文问题并强制覆盖。下载所有依赖whl包至指定文件夹，用于离线环境部署。

Python导出requirements.txt以及第三方库whl文件

  1. cd至项目根目录
  2. pip安装pipreqs（项目里会有很多 Python 库，但有些是系统自带的，有些是没用的，用这个只会导出你代码里真正 import 的第三方库）
1

pip install pipreqs -i https://pypi.tuna.tsinghua.edu.cn/simple
  1. 导出项目依赖
1

pipreqs ./ --encoding=utf8 --force

参数说明

  • ./ ：表示在当前项目根目录生成requirements.txt
  • --encoding=utf8：解决中文注释 / 路径的编码报错问题
  • --force：强制覆盖已存在的requirements.txt文件
  1. 下载所有依赖的whl包到指定文件夹（这里以whl_packages 为例）
1

pip download -r requirements.txt -d ./whl_packages -i https://pypi.tuna.tsinghua.edu.cn/simple
  1. 离线安装依赖（部署时用）
1

pip install -r requirements.txt -f ./whl_packages --no-index
